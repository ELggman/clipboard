~~~markdown
# 8. Code Mode（代码模式）

## 8.1 功能目标

Code Mode 用于识别剪贴板中的代码、命令、配置文件和结构化文本，并根据识别结果提供针对性的展示和操作能力。

Code Mode 不承担 IDE 功能，不负责编译、运行或调试代码。

核心目标：

1. 自动识别代码内容；
2. 自动判断编程语言；
3. 在历史记录中提供代码专属预览；
4. 对代码进行语法高亮；
5. 根据代码类型提供对应 Action；
6. 支持代码与普通文本之间的转换；
7. 支持将代码保存为文件；
8. 所有代码分析均默认在本地完成。

---

## 8.2 Code Mode 的触发条件

Code Mode 不要求用户手动开启。

系统检测到 Clipboard 内容后自动判断：

```text
Clipboard
    ↓
Content Detector
    ↓
Text?
    ↓
Code Detector
    ↓
Code Candidate?
    ├── No  → 普通 Text
    └── Yes → Code Mode
~~~

Code Mode 应该是一个**内容状态**，而不是一个全局开关。

## 8.4 代码检测

### 8.4.1 基本要求

系统必须区分：

```text
普通文本
```

和：

```text
代码
```

例如：

```text
Hello, how are you?
```

应该识别为：

```text
type = text
```

而：

```python
def hello(name):
    print(f"Hello {name}")
```

应该识别为：

```text
type = code
language = python
```

------

## 8.4.2 检测方法

第一版使用本地启发式规则。

检测依据包括：

- 语言关键字；
- 括号结构；
- 缩进结构；
- `{}`、`[]`、`()`;
- `;`;
- `#`;
- `//`;
- `def`;
- `class`;
- `function`;
- `import`;
- `SELECT`;
- `FROM`;
- `WHERE`;
- Shell 命令特征；
- Markdown Fence。

禁止第一版为了代码识别调用远程 API。

------

## 8.4.3 检测置信度

Code Detector 应产生：

```text
confidence
```

范围：

```text
0.0 ~ 1.0
```

例如：

```json
{
    "type": "code",
    "language": "python",
    "confidence": 0.94
}
```

建议：

```text
confidence >= 0.80
```

才自动标记为 Code。

否则：

```text
type = text
```

但可以保留：

```text
detected_language = python
```

作为辅助信息。

# 9. Privacy Mode（隐私模式）

## 9.1 功能目标

Privacy Mode 用于保护用户可能复制到剪贴板中的敏感信息。

可能包含：

```text

Private Key

个人信息
公司内部信息
```

核心原则：

> Clipboard Workspace 可以读取系统 Clipboard，但不应该默认永久保存所有 Clipboard 内容。


Sensitive Detection：

```text
< 20ms
```

对于普通文本：

```text
< 50ms
```

不应该因为代码检测或隐私检测明显阻塞 Clipboard Monitor。

------

## 11.3 Failure Handling

如果：

```text
Code Detector
```

失败：

```text
Fallback → Text
```

如果：

```text
Sensitive Detector
```

失败：

```text
Fallback → 根据当前 Privacy Policy
```

不得导致：

```text
Clipboard Monitor 崩溃
```

# 13. 最终设计原则

Code Mode：

> 让 Clipboard Workspace 理解“这是什么代码”。

Privacy Mode：

> 让 Clipboard Workspace 知道“什么内容不应该被保存”。

两者共同构成开发者使用场景的核心能力：

```text
                  Clipboard
                      │
          ┌───────────┴───────────┐
          ↓                       ↓
      Code Mode              Privacy Mode
          │                       │
   Language Detection      Sensitive Detection
          │                       │
   Syntax Highlight         Mask / Ignore
          │                       │
       Actions              Auto Expiration
          │                       │
          └───────────┬───────────┘
                      ↓
                SQLite History
```

最终要求：

**代码处理本地化、隐私检测本地化、Clipboard 数据本地化；任何远程 AI 能力只能作为后续可选 Action，不能成为核心功能依赖。**
